A wide bypasses contact. A no-ball continues contact where eligible. Contextual free-hit/no-ball dismissal masks apply **before** sampling. A winning automatic extra terminates immediately. Ordinary running outcomes beyond the target are masked before sampling, while complete four/six boundaries remain payable.

No mutable RNG cursor, `Math.random`, platform `Math.exp` or clock time determines outcomes. The returned trace is internal-only because it contains the hidden match seed.

A worker adapter and Node/Chromium/Firefox test source are present; worker/CLI compiled production execution is not yet verified.

## Defects, deviations and repairs

1. **Chase target overrun discovered and repaired.** Two/three-run ordinary categories could initially award runs beyond an imminent chase target and trip the domain scoring validator. The generator now removes impossible ordinary running categories before the integer draw, while awarding the full amount for four/six boundaries. Frozen seed regression source and two actual offline chase checks cover this. This was a new, not-yet-released generator correction. Original scorer/model/random identifiers and frozen reference corpora were not changed.
2. **Stale runtime disclosure repaired.** The capability contract and React shell no longer claim no generator is present. They expose the one-shot stage service but clearly mark production verification blocked and play disabled.
3. **Schema/test and CI scope repaired.** Source metadata/test schema counts now recognise 88 schemas, while 84 inherited schema files stay byte identical. CI installs Chromium and Firefox rather than only Chromium. Whether the **four additive structural mirrors exactly match authoritative Zod generation** remains an acceptance blocker and must be repaired based on real Zod output, not inferred as PASS.
4. **Explicit dependency updated.** Simulation now declares the existing `@lcxxvi/domain` workspace dependency, recorded in the lockfile as an additive internal dependency. No external version upgrades or model/fixture changes were made.
