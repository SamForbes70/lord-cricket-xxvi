# ADR 002: Runtime contracts are the type source

Accepted for Pass 01. Zod 4.1.12 strict schemas define boundary types; TypeScript types are inferred. Generate Draft 2020-12 schemas with stable URNs and commit them. Validate generated schemas independently with AJV. A drift check compares all generated bytes and detects extra schema files.

The pinned generator omitted fixed-tuple cardinality in its default output. The generation hook derives minItems, maxItems and items:false from the Zod tuple definition. A regression test checks runtime/schema parity for missing and extra team IDs. Unknown schema constructs fail generation; there is no permissive fallback.

Cross-field/referential validation is explicit in validation.ts, not hidden in refinements that JSON Schema cannot represent. Structural validation alone is insufficient for live match import. Cricket rules and result reconciliation are deferred to scoring/state milestones.

IDs use a 1..128 ASCII portable token alphabet (letters, digits, dot, underscore, colon, hyphen), start alphanumeric, and exclude prototype-sensitive names. This narrows the design's string ID representation for safe interchange without deriving identity from names or team membership. Player names retain the normative 1..80 Unicode code point bound. Dates use ISO calendar validation; SHA256 values are lowercase 64-digit hex.
