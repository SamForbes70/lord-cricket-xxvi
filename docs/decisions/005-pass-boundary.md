# ADR 005: Report the pass separately from M0 and release gates

Accepted for Pass 01. A successful repository/contracts pass does not complete M0. There is no fictional world pack or independent cricket scoring corpus yet. No scorer, reducer implementation, random sampler, playable match, AI policy, score projection or storage adapter is supplied.

The React shell exposes a contract checker and disables play with an explanation. The CLI reports machine-readable capabilities. Stub interfaces never return fabricated successful simulation outcomes. Reserved fields are not presented as functional tactical controls.

Pass 02 is Scoring Fixtures: manually define Appendix D expectations, especially all run-out batter/end variants, before implementing the deterministic scorer. Preserve provenance and independent expected values. Keep stochastic generation out of scoring development.
