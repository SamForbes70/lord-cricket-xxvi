**Known integrity gap.**
- "Next delivery" and "Finish over" give the computer captain a step before every ball.
- "Next decision", "Finish innings" and "Finish match" advance an over per command. "Next key moment" advances a ball per command without the computer's plan steps. In these modes the computer's plans change only at over boundaries or when it is the side to decide.
- Against a computer side, the same match can therefore produce different results depending on which button the player presses. [Inference] This does not affect matches with no computer side and nothing delegated, because the balls' random draws are keyed by attempt ordinal and no plans change.
- **Proposed fix:** run the computer captain's per-ball steps inside the match worker, so every advancement mode applies the same decisions in the same order. The page then sends one command, which also avoids the cost of a page round trip per ball in long matches. A test will play one seed through each mode and require identical event logs.
