# Claude Code instructions

Read `AGENTS.md` first: it is the project's instruction file and it applies to you. Then read `docs/HANDOVER.md` (one page: where the project stands, how to run and verify it, what is next) and `docs/AI_CONTINUATION.md` (working agreements for any AI).

Short version: work on a branch and open a draft pull request, never push to `main`; run `npx tsc -b` after every pull; check exit codes; record PASS, FAIL, BLOCKED or NOT RUN with the exact command and revision; do not widen a persisted format without a new version; do not mark an owner gate passed or change repository settings; if a permission is denied, stop and tell the owner.
